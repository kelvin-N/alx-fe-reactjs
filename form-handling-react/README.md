# form-handling-react

A React project demonstrating **form handling** using **Formik** and **Yup** validation.  
The project includes a **user registration form** that validates input, submits data to a mock API, and displays inline success/error messages.

---

## Features

- Form handling with **Formik**
- Input validation using **Yup**
- Inline success/error messages
- Submits form data to a mock API (JSONPlaceholder)
- Clean and responsive UI
